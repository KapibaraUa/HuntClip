# Отчёт по фазе 1: MVP в командной строке

Статус: **ждёт проверки**. CLI `cliphunter run` и пайплайн этапов S0–S4, S7 полностью реализованы, покрыты тестами и проверены на синтетическом видео.

## Что сделано

1. **CLI `cliphunter` (`src/cliphunter/cli.py`):**
   - Команда `cliphunter run <target>`: принимает ссылку на YouTube или локальный файл, профиль стримера (`--profile`), лимит бюджета (`--budget`), границы длительности (`--min-len`, `--max-len`), каталог вывода (`--out`) и флаг подтверждения (`--yes`).
   - Команда `cliphunter estimate <target>`: быстрая оценка длительности, токенов и стоимости без запуска обработки.
2. **S0 Ingest (`src/cliphunter/ingest/`):**
   - Распознавание YouTube URL, локальных видеофайлов и других ссылок (`probe.py`, `files.py`).
   - Извлечение метаданных (длительность, название, канал, sha256).
   - Оценка стоимости сканирования и интерактивный запрос подтверждения, если сумма превышает `CONFIRM_ABOVE_USD` (по умолчанию 1 USD).
3. **S1 Download & Proxy (`src/cliphunter/pipeline/stages.py`, `video/ffmpeg.py`):**
   - Загрузка видео через yt-dlp (для ссылок).
   - Генерация 720p 24fps CRF 30 AAC 96k прокси через FFmpeg для подачи в Gemini.
4. **S2 Chunk Plan (`src/cliphunter/pipeline/chunking.py`):**
   - Видео <= 45 мин (`SHORT_VIDEO_MAX_S`) обрабатываются одним куском.
   - Длинные видео разбиваются на куски по `CHUNK_S` (2700 с) с перекрытием `OVERLAP_S` (120 с) и шагом 2580 с.
   - Защита контекста: проверка `chunk_fits_context` (<60% контекстного окна модели).
5. **S3 Scan (`src/cliphunter/llm/scan.py`):**
   - Проход 1 поиска с системным промптом `prompts/scan.md` (версия 1) на разрешении `media_resolution=low`.
   - Загрузка кусков в Files API Gemini (до состояния ACTIVE).
   - Валидация structured output Pydantic-схемой `ScanResponse`, перевод локальных таймкодов ММ:СС в глобальную шкалу секунд видео.
   - 1 автоматический повтор при невалидном JSON, корректная обработка блокировок по безопасности (статус куска `partial`).
6. **S4 Merge & Dedupe (`src/cliphunter/pipeline/merge.py`):**
   - Слияние кандидатов из соседних кусков с перекрытием >= 50% от более короткого. Выигрывает кандидат с большим score, evidence и title_options объединяются.
   - Фильтрация по допустимой длительности `[CLIP_MIN_S - tolerance, CLIP_MAX_S + tolerance]`.
   - Ограничения покрытия: не более `MAX_PER_30MIN` клипов на любое 30-минутное окно и потолок `MAX_CANDIDATES_PER_HOUR`.
7. **S7 Cut & Export (`src/cliphunter/video/cut.py`, `export/manifest.py`):**
   - Покадровая точная нарезка из оригинала через FFmpeg с перекодированием libx264 CRF 18 и аудио-затуханиями `afade`.
   - Проверка каждого готового клипа через `ffprobe` (наличие видео, аудио, соответствие длительности с допуском 0.15 с).
   - Экспорт итогового `manifest.json` и клиповых манифестов.
8. **Идемпотентность и возобновление (`stages.py`):**
   - Состояние задачи сохраняется на каждом этапе в `data/jobs/{job_id}/state.json`.
   - При сбое или перезапуске пайплайн продолжает работу с последнего завершённого этапа без повторных затрат токенов.

## Допущения

1. До введения базы данных PostgreSQL (в фазе 3) состояние задач хранится в структурированных файлах `state.json` в `data/jobs/{job_id}/`.
2. При слиянии кандидатов текстовые свидетельства объединяются через разделитель ` | `, а заголовок и границы берутся у кандидата с наивысшей оценкой.
3. В фазе 1 проходы refine (S5) и judge (S6) не выполняются (они входят в фазу 2), поэтому нарезка S7 идёт сразу по отфильтрованным после S4 кандидатам.

## Что не получилось / Ограничения

2. Поддержка аппаратного ускорения NVENC заложена параметром `--use-nvenc`, но по умолчанию отключена для максимальной совместимости.

## Как проверить результат самостоятельно

1. **Запустить тесты и линтеры:**
   ```powershell
   uv run pytest -q
   uv run ruff check . ; uv run ruff format --check . ; uv run mypy
   ```

2. **Проверить CLI в терминале:**
   ```powershell
   uv run cliphunter --help
   ```

3. **Оценить стоимость любого видео:**
   ```powershell
   uv run cliphunter estimate "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
   ```

4. **Запустить тестовую нарезку на своём видеофайле:**
   ```powershell
   uv run cliphunter run C:\path\to\stream.mp4 --yes
   ```
   В результате в каталоге `data/out/{job_id}/` появятся готовые mp4-клипы и `manifest.json`.
