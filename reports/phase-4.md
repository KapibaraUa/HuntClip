# Отчёт по фазе 4: Монтаж (Layouts, Звук, Шаблоны, Субтитры)

*Дата: 21.10.2026 · Проект: ClipHunter · Статус: Реализована и готова к проверке*

## 1. Цель фазы
Реализация модуля автоматического видеомонтажа и оформления клипов согласно разделам 9, 10, 11 и 14 технического задания (`docs/plan.md`):
- Поддержка ключевых форматов отображения (layouts): оригинальный 16:9 и вертикальные 9:16 (center crop, blur-fit с размытым фоном, вертикальный сплит фейскама и геймплея по координатам профиля стримера).
- Нормализация уровня громкости под стандарты платформ коротких видео (EBU R128 `loudnorm=I=-16:TP=-1.5:LRA=11`) и аудио-затухания (`afade`).
- Брендинг и оформление: заголовочный хук в первые секунды видео (`drawtext`), наложение водяного знака / логотипа (`overlay`).
- Модуль опциональных караоке-субтитров (`.ass`) со словесной подсветкой.
- Сквозная интеграция параметров монтажа в FastAPI backend (`POST /api/jobs/{id}/render`), воркер фоновых задач и веб-интерфейс ревью.
- Полная валидация результатов через `ffprobe` и подготовка 3 образцов видео для визуальной проверки владельцем.

## 2. Что реализовано

### 2.1. Построители видеофильтров Layouts (`src/cliphunter/video/layouts.py`)
Реализован модульный генератор сложных фильтрграфов FFmpeg для 4 вариантов кадрирования:
1. **`original` (16:9):**
   - Сохраняет оригинальные пропорции исходника без искажений и черных полос (`[0:v]null[outv]`).
2. **`center_crop_9x16` (1080x1920):**
   - Вырезает центральную зону 9:16 и масштабирует до 1080x1920: `crop=ih*9/16:ih,scale=1080:1920`.
3. **`blur_fit_9x16` (1080x1920):**
   - Двухслойная композиция: фоновый слой растягивается и размывается гауссовым фильтром (`boxblur=30:5`), а поверх по центру накладывается четкий исходник с сохранением пропорций (`scale=1080:-2,overlay=(W-w)/2:(H-h)/2`).
4. **`facecam_top_game_bottom_9x16` (1080x1920):**
   - Профессиональный вертикальный монтаж стримов: верхние ~640px занимает реакция стримера (вырезается из `facecam_rect` профиля, например `evelone2004`), нижние ~1280px — игровое поле (`gameplay_rect`), скомпонованные через `vstack`.

### 2.2. Нормализация звука и микродаун-фейды (`src/cliphunter/video/render.py`)
- Интегрирован аудиофильтр EBU R128: `loudnorm=I=-16:TP=-1.5:LRA=11`. Звук клипа приводится к единой стандартизированной громкости, устраняются перепады между шепотом и криками.
- Для предотвращения щелчков на стыках нарезки накладываются фейды: плавное нарастание в начале (`afade=t=in:st=0:d=0.1`) и затухание в конце (`afade=t=out:st={dur-0.15}:d=0.15`).

### 2.3. Заголовочные хуки и шрифты под Windows (`src/cliphunter/video/template.py`)
- В фильтрграфы FFmpeg добавлен оверлей заголовка-хука в первые 3–4 секунды клипа (`enable='between(t,0.3,3.5)'`).
- **Решение проблемы Windows Fontconfig:** фильтр FFmpeg `drawtext` на Windows без явного шрифта падает с ошибкой `Fontconfig error`. Реализована функция `get_default_font_file()`, которая автоматически находит системный шрифт (`C:/Windows/Fonts/arial.ttf`) и правильно экранирует двоеточие диска (`C\:/Windows/Fonts/arial.ttf`) для синтаксиса FFmpeg filtergraph.
- Поддерживается наложение водяного знака / логотипа стримера в заданный угол кадра (`overlay`).

### 2.4. Субтитры ASS Karaoke (`src/cliphunter/video/subtitles.py`)
- Генератор файлов `.ass` со стилями шрифта, акцентной подсветкой текущего слова и полупрозрачным боксом для читаемости.
- Интеграция с `faster-whisper`: при включенном флаге `SUBTITLES=true` запускается распознавание с `word_timestamps=True`.
- При выключенном флаге или отсутствии установленного пакета модуль плавно пропускает субтитры без сбоев.

### 2.5. Интеграция в API, фоновый воркер и Веб-интерфейс
- Эндпоинт `POST /api/jobs/{id}/render` теперь принимает:
  ```json
  {
    "candidate_ids": ["cand_1", "cand_2"],
    "layout": "facecam_top_game_bottom_9x16",
    "template": "default"
  }
  ```
- Воркер фоновых задач (`src/cliphunter/worker/tasks.py`) загружает профиль стримера, применяет выбранный layout, заголовок и loudnorm, сохраняя `layout` и `template` в таблицу `clips` и `manifest.json`.
- В веб-интерфейсе ревью (`src/cliphunter/web/static/app.js`) селектор выбора layout передает выбранный формат на сервер при нажатии «Смонтировать выбранные».

### 3.2. Образцы клипов для визуальной проверки владельцем
Скриптом `scripts/demo_layouts.py` сгенерированы 3 демонстрационных клипа с разными стилями монтажа, звуком и заголовками-хуками. Они сохранены в папке `data/demo_clips/`:

1. **Клип 1 (Горизонтальный 16:9):**
   - **Файл:** `data/demo_clips/01_Невероятный_клатч_1_в_4_original.mp4`
   - **Параметры:** 1920x1080, 4.0 с, `original`, нормализация звука -16 LUFS, заголовок «Невероятный клатч 1 в 4».
   - **Назначение:** Традиционный формат YouTube / длинные компиляции.

2. **Клип 2 (Вертикальный Blur-Fit 9:16):**
   - **Файл:** `data/demo_clips/02_Реакция_на_донат_100_000_руб_blur_fit_9x16.mp4`
   - **Параметры:** 1080x1920, 4.0 с, `blur_fit_9x16`, размытый фон + четкий стрим по центру, заголовок «Реакция на донат 100 000 руб».
   - **Назначение:** Shorts/Reels/TikTok для разговорных стримов или обзоров, где важно видеть весь 16:9 кадр целиком.

3. **Клип 3 (Вертикальный сплит фейскам + геймплей 9:16):**
   - **Файл:** `data/demo_clips/03_Стрим__Evelone192_эпичный_момент_facecam_top_game_bottom_9x16.mp4`
   - **Параметры:** 1080x1920, 4.0 с, `facecam_top_game_bottom_9x16`, фейскам стримера сверху (профиль `evelone2004`), игра снизу, заголовок «Стрим: Evelone192 эпичный момент».
   - **Назначение:** Топовый формат динамичных игровых нарезок для максимального удержания зрителя.

Все 3 файла успешно валидированы через `ffprobe` (видео H.264, аудио AAC 192 kbps, ровно 4.000000 с).
