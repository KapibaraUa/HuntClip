# Отчёт по фазе 0: основа и калибровка

Статус: **ждёт проверки**. Приёмка по плану выполнена частично: калибровочные измерения (пункты 1–7 раздела 8) не сняты, потому что нет стрима, эталонных моментов, а тратить деньги на калибровку нельзя.

## Что сделано

- Скелет репозитория по разделу 5 (пустые пакеты для будущих фаз), `pyproject.toml`, Python 3.12 в локальном `.venv` через `uv`.
- `config.py`: все переменные раздела 12 плюс несколько служебных (список в `docs/DECISIONS.md`, п. 9). `.env.example` покрыт тестом на полноту.
- `logging.py`: JSON-логи, поле `job_id`, маскирование ключей и токенов.
- `llm/`: схемы из Приложения B, бюджет и расчёт цены, кэш, клиент `GeminiVideoClient.call()` (проверка бюджета, учёт usage, журнал вызовов в JSONL, кэш, повтор на 429/5xx), загрузчик промптов. Промпты A.1–A.3 в `prompts/` с `version: 1`.
- `pipeline/timecodes.py`: `parse_ts`, `format_ts`, `to_global`, `within_chunk`.
- `video/ffmpeg.py` (прокси по S1), `ingest/youtube.py` (yt-dlp, нужная секция).
- `docker-compose.yml` (Postgres 16, Redis 7), `.github/workflows/ci.yml`, `Makefile`, pre-commit.
- `scripts/calibrate.py` по пунктам 1–7 (см. ниже) и `docs/CALIBRATION.md`.
- `docs/DECISIONS.md`, `docs/PROGRESS.md`, README.

## Допущения

Полный список в [docs/DECISIONS.md](../docs/DECISIONS.md). Главные: Interactions API вместо generateContent; `URL_OFFSETS_OK=false` и `URL_TS_RELATIVE_TO_WINDOW=true` пока заглушки; «обычное разрешение» = `high`; токены tool-use считаются входными; журнал вызовов в JSONL, а не в БД.

## Что не получилось

1. Измерения калибровки (нет данных и бюджета). Решение «включать ли url-mode с offsets» **не принято**; до калибровки работаем в file-mode.
2. Сверка не завершена по пунктам: допустимые safety settings, RPM/TPM вашего тарифа, срок хранения в Files API, максимум видео в запросе, лимит Bot API Telegram.
3. Платная часть `calibrate.py` (`--live`) проверена только на подставном клиенте, на реальном API не запускалась. Возможны мелкие поправки при первом запуске (например, формат поля `uri` для YouTube без `mime_type`).
4. CI не запускался (нет удалённого репозитория), контейнеры Docker не поднимались (проверен только `docker compose config`).

## Как проверить самому

```powershell
uv sync --python 3.12
uv run pytest -q
uv run ruff check . ; uv run ruff format --check . ; uv run mypy
uv run python scripts/calibrate.py --config golden/calibration.example.yaml   # сухой прогон, 0 USD
docker compose up -d                                                            # Postgres и Redis
```

Чтобы закрыть калибровку: скопировать `golden/calibration.example.yaml` в `calibration/calibration.yaml`, вписать ссылку на стрим (evelone2004) и 5 или больше моментов, положить ключ в `.env`, затем запустить с `--live` (потолок трат `CALIBRATION_MAX_COST_USD=1.0`). Скрипт сам перепишет `docs/CALIBRATION.md`.
