# golden/

Эталонные моменты: для каждого стрима JSON с моментами, которые человек считает лучшими
(`start_s`, `end_s`, примечание). Используется в фазе 2 (`make eval`).

В фазе 0 здесь лежит только пример входа для калибровки: `calibration.example.yaml`.
Скопируй его в `calibration/calibration.yaml` (папка в `.gitignore`), впиши ссылку и моменты.
